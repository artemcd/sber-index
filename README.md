# Локальный код

Интерактивный атлас экономических типов муниципалитетов для трека «Кластеризация»
конкурса СберИндекса. По данным за 2023–2024 годы модель сравнивает структуру
безналичных расходов, доступность рынков и транспортное окружение 2016 территорий
на 24 помесячных срезах.

## Короткий глоссарий

- **МО** — муниципальное образование; **тип (кластер)** — группа территорий с похожими признаками, не рейтинг.
- **K** — число типов; **срез** — данные и разбиение за один месяц.
- **KMeans** распределяет все МО по заданному K; **HDBSCAN** ищет плотные группы без заданного K и может оставить часть МО без типа («шум»).
- **Атрибутированный граф** — муниципалитеты как узлы, транспортные связи как рёбра, экономические показатели как признаки.
- **Индекс расходов** — безналичные расходы относительно медианного МО того же месяца (медиана = 100).
- **SW / silhouette** — насколько МО ближе к своему кластеру, чем к соседнему; выше — лучше разделение.
- **ARI** — сходство двух разбиений с поправкой на случайность; 1 означает полное совпадение.
- **Модулярность** — преобладание связей внутри кластеров по сравнению со случайной моделью графа.
- **Устойчивое ядро** — МО с одним типом минимум в 22 из 24 месяцев и достаточным отрывом от альтернатив; **переход** — смена типа, удержанная минимум по три месяца до и после.

## Результат (лендинг)

- [Режим СберИндекса](https://artemcd.github.io/sber-index/) — 3 типа для 2016 муниципалитетов, динамика каждого и сопоставимые территории.
- [Режим с населением Росстата](https://artemcd.github.io/sber-index/external.html) — те же 2016 исходных территорий; в модели с 4 типами участвуют 1923, сопоставленные за оба года.

В первом режиме на декабрь 2024 года выделены «Цифровая повседневность»
(1191 МО), «Автономные локальные центры» (414) и «Крупные центры» (411).

Динамическая сеть выбрана из четырёх проверенных методов за небольшой выигрыш
по silhouette и временному ARI. Другие методы лидируют по отдельным метрикам;
качество на новых месяцах не проверено. Это ретроспективная типология.

HDBSCAN также проверен помесячно на тех же признаках и динамической сети.
При `min_cluster_size=50`, `min_samples=10` он назначает тип только 35% территорий
в режиме СберИндекса и 45% — с Росстатом (среднее за 24 месяца). Поэтому он
показан как альтернатива, но не заменяет карту с полным охватом; [результаты](artifacts/comparison/hdbscan_comparison.csv).

## Быстрый просмотр

Готовые данные двух режимов входят в репозиторий.

```bash
make check
make serve
```

Откройте `http://localhost:8000` или `http://localhost:8000/external.html`.
`make check` проверяет целостность данных сайта без повторного обучения.
Открытие HTML через `file://` не работает из-за загрузки локальных JSON.

## Воспроизведение расчёта

Нужны Python 3.12/3.13, `uv`, `make` и исходные файлы:

- [архив муниципальных данных СберИндекса](https://sberbank.com/common/img/uploaded/files/pdf/sberindex/hackathonlicence.zip) — `data/raw/hackathonlicence.zip` и распакованные Parquet в `data/raw/hackathon/hackathonlicence/`;
- [справочник и границы муниципалитетов](https://sberindex.ru/ru/research/dataset-borders-and-changes-of-municipalities) — `data/raw/municipal_boundaries.rar`, `municipal_metadata.pdf` и распакованные `data/raw/boundaries/t_dict_municipal_districts.xlsx`, `t_dict_municipal_districts_poly.gpkg`;
- [население муниципалитетов Росстата](https://rosstat.gov.ru/compendium/document/13282) — `data/raw/rosstat/BUL_MO_2023.xlsx` и `BUL_MO_2024.xlsx`.

Исходные данные не включены в Git. Из корня репозитория:

```bash
uv sync --locked
make all
```

`make all` выполняет аудит, обучение и сравнение моделей, сопоставление с
населением, сборку обоих лендингов и `make check`. Расчёт работает на CPU и
перезаписывает производные файлы в `artifacts/`, `reports/` и `site/`.
Отдельная проверка устойчивости годовой модели доступна через `make validate`,
но не входит в `make all`. Полный запуск проверен 6 октября 2026 года на macOS
с Python 3.13.

В расширенном режиме население и доля городских жителей добавлены к признакам
СберИндекса. Зарплата и отраслевая занятость пока не включены: [БД ПМО Росстата](https://rosstat.gov.ru/storage/mediabank/munst.htm)
выгружает муниципальные показатели 8423007 и 8423005 по субъектам, а не единым
файлом для страны. Региональные значения не подставляются вместо муниципальных.

Папку `site/` публикует [GitHub Actions](.github/workflows/pages.yml) после
изменений в `main`; для первого запуска Pages нужно выбрать `Source: GitHub Actions`.
