# Аудит исходных данных

## Решение по выборке

Основная модель будет строиться на сбалансированной панели из **2016 муниципалитетов**:
для них присутствуют все 24 месяца и все шесть категорий. Все
**2190 муниципалитетов** останутся в дополнительной
проверке чувствительности. Такое разделение не смешивает экономические переходы с
изменением состава наблюдаемой выборки.

## Территориальный справочник

- актуальных на 2024 год `territory_id`: 2594;
- ID в расходах, но не в актуальном срезе справочника:
  [1471, 1487, 1847];
- актуальных ID без расходов: 407;
- актуальных ID без индекса доступности рынков: 23;
- актуальных ID без любых конкурсных показателей:
  [411, 845, 894, 1156, 1516, 2350].

ID 1471, 1487 и 1847 присутствуют только в 2023 году и прекратили существование после
муниципальных объединений. Для карты и временных переходов версия территории должна
выбираться по году наблюдения, а не только по состоянию на 2024 год.

## Транспортные связи

| type    | rows    | nodes | unique_pairs | duplicate_rows | conflicting_distance | zero_distance |
| ------- | ------- | ----- | ------------ | -------------- | -------------------- | ------------- |
| highway | 3303736 | 2573  | 3303736      | 0              | 0                    | 148           |
| railway | 2638628 | 1627  | 1319314      | 1319314        | 0                    | 0             |

Железнодорожные связи записаны в обе стороны: 1,319,314 строк
повторяют уже имеющиеся неориентированные пары. Пар с разными расстояниями: 0.
Перед использованием связи нужно привести к
канонической паре `(min(id), max(id))`. В автодорожных данных есть
148 нулевых расстояний, поэтому величина `1 / distance`
не может применяться напрямую.

## Несоответствия документации данным

1. В PDF поле расходов называется `consumption`, в parquet оно называется `value`.
2. PDF утверждает, что транспортная пара хранится один раз, но для железной дороги
   каждая доступная пара представлена в обоих направлениях.
3. В PDF указано 22 муниципалитета без индекса доступности рынков, тогда как
   относительно актуального справочника отсутствуют 23.

Эти расхождения учитываются явно; исходные таблицы не исправляются на месте.
